# ZHIBEK 5: план

## Что меняется по сравнению с версией 4

1. **Модель сайта.** Не «породы + котята», а «порода → коты этой породы». Котята и взрослые лежат в одном списке одной породы, различаются меткой и фильтром «Котята / Взрослые». Хозяин добавляет котов сам.
2. **Дизайн.** Версия 4 была аккуратной, но однотипной: пастельные карточки, один шрифт, одинаковые скругления. Версия 5 строится на присланных ChatGPT-ассетах: настоящие вырезанные коты на насыщенных фонах, наклейки как язык оформления, выглядывающий кот.
3. **Тексты** остаются короткими и конкретными.

## Дизайн-язык

- **Бумага и чернила.** Фон бумаги `#f2e9db`, чернила цвета эспрессо `#1f1410`.
- **Цвета пород — драгоценные тона**, на которых коты «загораются»: абиссинская — хвойный зелёный `#2c4a3b`, бенгальская — бордо `#6a2230`, сиамская — кобальт `#2a46a0`. Для новой породы цвет задаётся в карточке.
- **Шрифты.** Lora 600 (заголовки умеренного размера, курсив для акцента), Onest (текст), Caveat (рукописные пометки со стрелками: единственное «человеческое» пятно среди гладких картинок).
- **Наклейки** (лапа, мордочка, силуэт, спящий кот, ушки, усы, клубок, рыбья кость, хвост, прыгающий кот) — маркеры шагов, разделитель, 404, подвал. Всегда с мягкой тенью и небольшим наклоном.
- **Формы.** Арка для карточек котов, крупные скругления для панелей, полосы на всю ширину. Никаких одинаковых «карточек в ряд».
- **Движение** минимальное: появление блоков, переворот карточек характеров, подсветка городов на карте и одна сцена с котом на странице бенгала. Свечений, частиц, бегущих лент и наклеек нет.

## Структура

| Маршрут | Содержимое |
|---------|-----------|
| `/` | герой «Выберите породу» → коты с фильтрами (если есть) → три характера → как забрать → доставка (карта) → вопросы → журнал → заявка |
| `/breeds/` | переход к породе, чередующиеся полосы, таблица сравнения, подсказка |
| `/breeds/{порода}/` | порода на своём цвете, крупный кот, пометки на кота, все коты породы с фильтром, текст; у бенгала сцена с котом справа |
| `/cats/` | все коты с фильтром по породе |
| `/cats/{кот}/` | галерея, факты, родители, кнопки |
| `/kittens/…` | 301 на `/cats/…` |
| журнал, страницы, 404 | в той же системе |

## Данные (плагин 4.0)

- Запись `zhibek_cat` («Коты») вместо `zhibek_kitten`; старые записи переносятся при обновлении.
- Статусы: свободен, в резерве, ожидается, в новой семье, производитель.
- Категория «котёнок/взрослый» вычисляется по дате рождения (младше года — котёнок) или задаётся вручную.
- Для породы: оценки характера (активность, голос, размер, уход) для сравнения.
- Демо: 12 котов (по 4 на породу).

## Картинки

`theme/assets/img/pets` — коты на прозрачном фоне (позы пород), `pets/peek.webp` — кот, выглядывающий из-за края.
Все картинки пока заглушки: их сгенерировал ChatGPT или они взяты из интернета.
