# Ассеты

## Откуда что

| Файл | Источник |
|------|----------|
| `img/pets/*.webp` | коты на прозрачном фоне: сгенерированы в ChatGPT, обрезаны и пережаты `scripts/prepare_pets.py` (основной размер и лёгкая версия `-sm`) |
| `img/pets/*-head.webp` | головы пород для блока сравнения характеров, вырезаются из сидящих поз тем же скриптом |
| `img/pets/peek*.webp` | кот выглядывает: окно заявки, нижний блок страниц, пустые состояния |
| `anim/bengal-bottom`, `anim/bengal-right` | кадры анимации кота при прокрутке (47 и 33 кадра), присланы владельцем, уменьшены до 800×600 (`scripts/prepare_frames.py`), пустые кадры и «уход» кота убраны (`scripts/trim_frames.py`) |
| `img/ui/*` | фавикон, иконка для iOS, картинка для соцсетей 1200×630 |
| `fonts/*` | Onest, Lora, Caveat — Google Fonts, SIL OFL |
| карта Казахстана | Natural Earth; проекция и города — `scripts/kzmap.mjs`, результат — `theme/inc/map.php` |

Все изображения — заглушки, пока питомника нет.

## Когда появятся свои фото

1. Для котов: вырезанный на прозрачном фоне кот (PNG/WebP) идёт в «Изображение записи» с отметкой «вырезано». Обычное фото тоже подходит.
2. Для пород: так же, в карточку породы. Загруженное фото заменяет иллюстрацию в шапке и в карточках.
3. Анимация кота при прокрутке: замените кадры в `theme/assets/anim/bengal-*` (те же имена `frame_0001.webp`…) или добавьте свои сцены по образцу `zh_scene()` в `theme/inc/helpers.php`.

## Как делать новые картинки

Подойдёт тот же приём, что для присланных ассетов: кот целиком на ровном белом фоне, затем вырезка. Для вырезки есть `scripts/cutout.py` (нужны `rembg`, `pymatting`), для увеличения — `scripts/upscale.py`. Для набора поз (сидит, стоит, потягивается…) держите один и тот же окрас и свет.
