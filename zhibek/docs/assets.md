# Ассеты

## Откуда что

| Файл | Источник |
|------|----------|
| `img/cats/*.webp` | вырезанные коты из студийных кадров прежней сборки (иллюстрации, не фото питомника), увеличены вдвое нейросетью EDSR: `scripts/upscale.py` |
| `img/scenes/*.webp` | студийные кадры прежней сборки: три породы, котята, дом; для каждого есть версии 640 и 960 px |
| `img/products/*.webp` | кадры товаров прежней сборки, разрезанные на четыре снимка |
| `img/ui/*` | фавикон, иконка для iOS, картинка для соцсетей 1200×630 — собраны для этого сайта |
| `fonts/Onest.woff2` | Onest, Google Fonts, SIL OFL; подрезан запросом `text=` (латиница, кириллица, казахские буквы, ₸) |
| карта Казахстана | Natural Earth через `world-atlas`; проекция и города — `scripts/kzmap.mjs`, результат — `theme/inc/map.php` |

Все изображения — заглушки, пока питомника нет. Стоковые сайты были недоступны из среды сборки, поэтому фотографий из интернета в тему не включено.

## Когда появятся свои фото

1. Снимите кота на ровном светлом фоне, от 1500 px по высоте.
2. Вырежьте фон (`python3 scripts/cutout.py фото.jpg x0,y0,x1,y1 кот.png`, нужны `rembg` и `pymatting`, или любой редактор) и при желании увеличьте (`scripts/upscale.py`).
3. Загрузите PNG/WebP в «Изображение записи» породы или котёнка и отметьте «Вырезано на прозрачном фоне». Обычную фотографию тоже можно загрузить, она показывается как есть.
4. Большие кадры на главной (три породы, дом, котята) лежат в `theme/assets/img/scenes`. Замените их своими файлами 1536×1024 с теми же именами и добавьте версии `-640` и `-960`.
