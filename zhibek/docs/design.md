# Дизайн-система ZHIBEK 4

## Идея

Спокойный редакционный сайт: светлая тёплая бумага, один крепкий шрифт, цветные «панели» пород и крупные фотографии. Никаких закреплений через JavaScript, WebGL и перехвата прокрутки: страница прокручивается так, как привык браузер, а движение добавляют только CSS и короткие появления блоков.

Знак — радужка с вертикальным зрачком. Он же заменяет букву I в названии, служит маркером у надписей над заголовками и рисует тонкую акцентную линию.

## Цвет

| Токен | Значение | Где |
|-------|----------|-----|
| `--paper` | `#f3ece0` | фон страницы (близок к фону студийных фото) |
| `--paper-2` | `#eadfcc` | вторичные блоки, чипы |
| `--card` | `#fbf8f2` | карточки, поля форм |
| `--ink` | `#17130f` | заголовки, кнопки, подвал |
| `--ink-2` | `#3a322a` | основной текст |
| `--muted` | `#645a4d` | подписи (контраст на фоне не ниже 5,3:1) |
| `--clay` | `#a3481f` | акцент: зрачок в логотипе, номера шагов, наведение на кнопки |

Цвета пород (фон панелей и карточек): абиссинская `#b9c7b0` (шалфей), бенгальская `#e0c088` (мёд), сиамская `#a9bdd4` (пыльный голубой). Для новой породы цвет задаётся в карточке породы, поле «Цвет фона».

Проверка контраста выполнена автоматически (axe-core, WCAG 2.1 AA): нарушений нет на всех типах страниц.

## Типографика

Один шрифт: **Onest** (SIL OFL), переменный, веса 400–800. Он создан под кириллицу, имеет крупную строчную высоту и ровные цифры. Файл подрезан до латиницы, кириллицы, казахских букв и знака ₸ (41 КБ).

| Роль | Размер | Вес |
|------|--------|-----|
| H1 | `clamp(2.5rem, 5.6vw + .4rem, 5.75rem)` | 680, трекинг −0,04em |
| H2 | `clamp(2.125rem, 3.8vw + .5rem, 4.25rem)` | 650 |
| H3 | `clamp(1.375rem, 1vw + 1.05rem, 1.75rem)` | 620 |
| Текст | `clamp(1.0625rem, .6vw + .95rem, 1.1875rem)` | 400, межстрочный 1,6 |

Мелкого текста капсом с широким трекингом нет: подписи пишутся обычным регистром от 14 px.

## Сетка

Контейнер 1320 px, поля `clamp(20px, 4vw, 56px)`, вертикальный ритм секций `clamp(72px, 9vw, 136px)`. Радиусы: 12 / 20 / 28 / 40 px, кнопки — капсулы. Брейкпоинты: 600, 900, 960 px.

## Движение

| Приём | Реализация |
|-------|-----------|
| Появление блоков | `IntersectionObserver` добавляет класс, дальше CSS: прозрачность и сдвиг на 26 px, 0,9 с |
| Первый экран | CSS-анимация без JavaScript: заголовок поднимается строками, фото «раскрывается» через `clip-path` |
| Стопка пород | `position: sticky` с шагом отступа: панели накладываются друг на друга на экранах от 900 px; на телефоне панели идут по порядку, без наложения |
| Параллакс фото и котов | CSS scroll-driven animations (`animation-timeline: view()`), там, где браузер поддерживает; иначе картинки просто стоят |
| Переход между страницами | `@view-transition { navigation: auto }`: плавная смена, фото котёнка переезжает из карточки на страницу |
| Карточки, кнопки, ссылки | CSS-переходы |

При `prefers-reduced-motion: reduce` всё это отключается, а блоки остаются видимыми. Если скрипт не загрузился, через 4,5 секунды блоки показываются сами.

## Тексты

Короткие утверждения о фактах (вес, окрас, возраст отдачи) и понятные действия («Оставить заявку»). Без восклицаний, без слов вроде «магия» и «душа», без конструкций «не X, а Y» и троек. Все тексты главной лежат в `theme/inc/content.php`.
