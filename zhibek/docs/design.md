# Дизайн-система ZHIBEK 5

## Идея

Каталог устроен вокруг породы: выбрал породу — увидел её котов. Поэтому порода — главный герой дизайна: у каждой свой насыщенный цвет, на котором кот «загорается». Всё остальное спокойное: тёплая бумага, один гарнитурный шрифт для заголовков, один гротеск для текста, рукописные пометки для живой интонации.

## Цвет

| Токен | Значение | Где |
|-------|----------|-----|
| `--paper` | `#f2e9db` | фон страницы |
| `--ink` | `#1f1410` | заголовки, тёмные блоки |
| `--ink-2` | `#43372e` | текст |
| `--muted` | `#65584b` | подписи |
| `--clay` | `#b3401a` | акцентные слова в заголовках, номера |
| `--gold` | `#f0b95a` | акценты на тёмном |
| абиссинская | `#2c4a3b` | хвойный зелёный |
| бенгальская | `#6a2230` | бордо |
| сиамская | `#2a46a0` | кобальт |

Цвет новой породы задаётся в её карточке. Светлые (пастельные) значения из прежних версий игнорируются: на них не читается светлый текст.

## Типографика

- **Playfair Display** 800–900, курсив для акцентного слова: заголовки.
- **Onest** 400–800: текст и интерфейс (создан под кириллицу).
- **Caveat** 600: рукописные пометки со стрелками, подписи кадров.

Файлы подрезаны до латиницы, кириллицы, казахских букв и ₸ (Caveat: кириллица и цифры).

## Формы и композиция

- **Арка** для котов: верх арки, кот выступает за её край (CSS `clip-path` с отрицательным отступом сверху).
- **Панели** с радиусом 32–44 px для пород, финала, доставки.
- Названия набраны крупно; название породы стоит за котом.
- Наклейки (лапа, клубок, рыба…) только как маркеры шагов, разделители и 404, не как фон.

## Движение

| Приём | Реализация |
|-------|-----------|
| Выбор породы | `flex-grow` на наведение (десктоп); на телефоне горизонтальная лента со скролл-снапом |
| Лента | CSS-анимация `translateX`, пауза при наведении |
| Кот при прокрутке | `position: sticky` + 72 или 56 кадров WebP на `<canvas>`; кадры догружаются порциями, прокрутка не блокируется |
| Нить «как забрать» | JS пишет прогресс прокрутки в CSS-переменную, клубок катится по линии |
| Финал | `<canvas>`, 3–6 тысяч точек, пиксельный буфер, пауза вне экрана |
| Окно заявки | кот выезжает из-за края (CSS keyframes) |
| Переходы между страницами | View Transitions API, карточка кота плавно становится его страницей |
| Появление блоков | `IntersectionObserver` + CSS |

Нет перехвата прокрутки, нет библиотек. При `prefers-reduced-motion: reduce` всё статично, блоки видны. Если скрипт не загрузился, через 4,5 секунды блоки показываются сами. Если включена экономия трафика, кадры анимации не грузятся, показывается один кадр.
