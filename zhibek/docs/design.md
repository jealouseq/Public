# Дизайн-система ZHIBEK

## Идея

Сайт устроен как вход в дом: сначала врата, потом комната со светом, потом взгляд, а дальше три мира по числу пород. Тёмные «кинематографичные» главы чередуются со светлыми «галерейными» (кремовый фон совпадает с фоном студийных фото, поэтому кадры вписываются без рамок).

Главная метафора — глаз с вертикальным зрачком: логотип, эмблема на вратах, шейдер глаза, точки родословной и знак на обложке паспорта используют одну форму.

## Цвет

| Токен | Значение | Где |
|-------|----------|-----|
| `--ink-1` | `#0d0b09` | тёмные главы |
| `--cream` | `#e8d9c5` | светлые главы, цвет совпадает с фоном фото |
| `--paper` | `#f3ebdc` | журнал, проза |
| `--gold-1…3` | `#f6e4b4`, `#dcb976`, `#b38c47` | акценты на тёмном |
| `--gold-ink` | `#86642a` | золотой текст на светлом (контраст ≥ 4,5:1) |
| текст | `#efe6d4` на тёмном, `#17120c` на светлом | |

Цвета «миров»: абиссинская — бронза `#d28c45`, сиамская — лунная синева `#9fb6dd`, бенгальская — тёмное золото `#c8962f`. Цвета глаз: `#e0a63a`, `#a6cb5e`, `#5a98e0`. Для новых пород цвета задаются в карточке породы (поля «Цвет глаз» и «Фирменный цвет»).

## Типографика

- Заголовки: **Playfair Display** 500, кегль `clamp(2.4rem, 5.2vw, 5.4rem)`, трекинг −0,012em, курсив для акцентных слов. Плотный контрастный шрифт: хорошо читается и на тёмном, и на светлом фоне (первая версия на тонком Noto Serif Display 300 читалась хуже и была заменена).
- Текст и интерфейс: **Golos Text** 430 (чуть плотнее обычного 400 для светлого на тёмном), подписи — капсом, 700, 12–13 px, трекинг 0,2–0,3em. Шрифт разработан под кириллицу.
- Оба шрифта подрезаны под сайт: латиница, кириллица, казахские буквы, знак тенге ₸ (его нет в Playfair, для него работает запасной Golos). Файлы лежат в теме, внешние запросы не нужны.
- Приглушённый текст на тёмном — `#d2c8b3` и `#a89c87`, на светлом — `#473c30` и `#6c5f4d`.

## Движение

| Приём | Реализация |
|-------|-----------|
| Плавный скролл | Lenis + ScrollTrigger |
| Закреплённые сцены | `pin` + `scrub`, прогресс сцены — единственный источник состояния (откат назад работает сам) |
| Врата | две CSS-переменные: `--ajar` (по времени) и `--open` (по скроллу); створки, свет, герой читают их через `calc()` |
| Глаз | фрагментный шейдер WebGL2: шум для волокон радужки, зрачок-линза, блики, веки; зум и цвет — uniforms |
| Бенгальский мех | шейдер: ячейки Вороного → розетки, рельеф по `dFdx/dFdy`, свет следует за курсором |
| Частицы | точки на WebGL; цели берутся из альфа-канала фото, цвета — из пикселей; физика не зависит от частоты кадров |
| Шёлк | шейдер ткани: волнистая кромка, складки, золотая линия; два прохода (накрыть и открыть) |
| Карточки | 3D-наклон по курсору, параллакс кота внутри (`translateZ`) |
| Переход карточка → страница | клон карточки сохраняется, на новой странице «перелетает» в главное фото (FLIP) |
| Магнитные кнопки, курсор-метка | `quickTo` |

Всё это отключается в режиме «уменьшить движение» и выключателем в подвале.

## Сетка и отступы

Контейнер 1440 px, поля `clamp(20px, 4.2vw, 72px)`, вертикальный ритм секций `clamp(80px, 10vw, 160px)`. Круглые кнопки (радиус 999px), карточки 22–30 px.

## Тексты

Короткие утверждения без восклицаний и «не X, а Y». Каждая строка либо факт (вес, шерсть, окрас, возраст отдачи), либо понятное действие («Напишите нам»). Вместо общих слов о «любви и характере» — характеристики пород и конкретные шаги.
