# Ready-made mods and assets that could fit WARDOGS (research, Nov 2026)

Licences below are as listed on the Modrinth API / project pages on the day of the search; confirm the licence file of the exact
version before bundling anything. "Depend on" (the player installs it separately) is always safer than "bundle" (we ship its files).

## Guns / combat
| Project | Licence | Fit |
|---|---|---|
| Superb Warfare (NeoForge 1.21.1, 3.5M dl) | GPL-3.0 | Guns, cannons, vehicles. Own damage/economy model clashes with ours; useful as a reference for models, animations, vehicle controls. |
| TaCZ (Timeless and Classics Zero) unofficial 1.21.1 port | code GPL-3.0, assets reportedly CC BY-NC-ND | Data-driven gun packs; assets are no-derivatives, so do not repackage. |
| Just Enough Guns New (NeoForge) | GPL-2.0 (assets by permission) | Reference only. |
| Scorched Guns NeoForged | GPL-3.0 | Reference only. |
| A.V.A Guns | LGPL-3.0 | FPS-style guns, possible reference. |
| TaCZ x Guns Lights addon | LGPL-3.0 | Muzzle flash / tracers idea. |

## Buildings
No ready-made building pack matches the real Bakurani layout. Generic schematic sites (MineSchematic, Spaleforce, McBuild,
PhantomMarket) give free files but no licence per build. kogtyv "Towny and Village" has a USSR panel-housing city type (1.21.x
datapack, licence not checked). Conclusion: keep generating buildings from the game's own map and hand-model the landmarks.
