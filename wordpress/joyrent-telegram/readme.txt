Уведомления о новых бронях JOYRENT в личный Telegram или группу.

== Что нужно ==
Активные WooCommerce и JOYRENT Rentals 1.8.5 или новее.
Отдельный Telegram-бот, созданный через официальный @BotFather.
Исходящие HTTPS-запросы хостинга к api.telegram.org и работающий WordPress Cron / WooCommerce Action Scheduler.

== Установка ==
1. WordPress → Плагины → Добавить плагин → Загрузить плагин.
2. Выберите joyrent-telegram-1.0.0.zip, установите и активируйте.
3. Откройте WooCommerce → JOYRENT → Telegram.
Существующую тему и JOYRENT Rentals заменять для подключения Telegram не требуется, если версия Rentals не ниже 1.8.5.

== Подключение за несколько минут ==
1. Откройте https://t.me/BotFather в Telegram. Проверьте, что это официальный BotFather.
2. Отправьте /newbot и задайте имя и username бота.
3. Скопируйте токен в поле «Токен бота» в WordPress. Сохраните, пока уведомления выключены.
4. Откройте своего нового бота со своего аккаунта и нажмите «Запустить» или отправьте /start.
5. В WordPress нажмите «Найти чат», затем «Использовать этот чат».
6. Нажмите «Тестовое сообщение». Убедитесь, что оно пришло именно в ваш чат.
7. Включите «Отправлять новые брони в Telegram» и сохраните настройки.

Токен — пароль бота. Не отправляйте его в переписку и не публикуйте.
После сохранения токен не отображается в HTML. Пустое поле сохраняет прежний токен.
При компрометации перевыпустите токен в BotFather и замените его в WordPress.

Для группы: добавьте бота, разрешите ему писать и отправьте /start@username_бота в группе.
Числовой ID группы обычно отрицательный. Можно ввести его вручную.
«Найти чат» читает последние события Telegram без удаления событий и без изменения webhook.
Если бот уже обслуживает другой сервис через webhook, создайте отдельного бота JOYRENT.

== Что приходит ==
Номер брони, имя, телефон, дополнительный Telegram клиента (если указан),
язык клиента, консоль, даты, срок, геймпады, получение и адрес доставки,
стоимость аренды, условия доставки и залога, выбранные игры и пожелания.
В сообщении есть ссылка на эту бронь в админке WordPress.
Бронь остаётся ожидающей подтверждения: уведомление не означает оплату или подтверждение наличия.

== Надёжность ==
Отправка выполняется в фоне после сохранения завершённой брони.
Повтор формы не создаёт повторное уведомление. Подтверждённое Telegram сообщение повторно не отправляется.
При явном временном отказе Telegram выполняются ограниченные повторные попытки.
При обрыве соединения результат считается неизвестным: автоматического повтора нет, так как сообщение могло уже дойти.
В карточке брони WooCommerce показан статус. Перед ручным повтором неизвестного результата проверьте чат.
При смене токена или чата старые ожидающие сообщения не отправляются новому получателю автоматически.
Старые брони при включении не рассылаются. Email-уведомления сохраняются.
Совместим с обычным хранилищем заказов и WooCommerce HPOS.

== Если уведомление не приходит ==
Проверьте тестовое сообщение, ID чата, запуск бота и права в группе.
В WooCommerce → Статус → Запланированные действия найдите группу joyrent-telegram.
Проверьте работу WP-Cron / Action Scheduler и разрешённые исходящие запросы api.telegram.org на хостинге.
Для статуса «Результат неизвестен» сначала проверьте чат, затем при необходимости повторите вручную.
Не публикуйте токен, ответы HTTP или контакты клиентов при диагностике.

== Приватность и хранение ==
Контакты клиента отправляются только в выбранный владельцем чат.
Используйте личный или закрытый рабочий чат с ограниченным доступом.
В фоновых заданиях хранится только ID заказа, без токена и контактов.
В заказе хранится технический статус отправки и ID подтверждённого сообщения.
Токен хранится в закрытых настройках WordPress без autoload; доступ к настройкам — только у администратора.
Дополнительно можно задать JOYRENT_TELEGRAM_BOT_TOKEN в wp-config.php, тогда значение из файла имеет приоритет.
Удаление плагина удаляет его настройки, токен и запланированные отправки; сообщения, уже отправленные в Telegram, остаются в чате.
Удалять историю уведомлений следует отдельно в Telegram согласно вашим правилам хранения данных.
