# Серия из пяти постов (светлая бумага)

Файлы в `out/`: `paper_flags_*`, `paper_phone_*`, `paper_route_*`, `paper_care_*`, `paper_listen_*` (1080×1350 и 2160×2700). Генератор: `tools/make_papers.py` → `src/paper_*.html`. Отправляйте как фото.

## 1. «Три тревожных знака» (`flags`)
```
⚠️ **Три тревожных знака**

Семьи пропавших часто становятся мишенью недобросовестных людей. Будьте внимательны, если вам говорят:
▫️ «найдём гарантированно»
▫️ «решайте срочно, сегодня»
▫️ «у нас закрытый доступ к данным»

Честная помощь так не говорит. Нет гарантий, нет спешки, нет тайн.

> Сомневаетесь — не спешите. Спросите нас.

📩 Контакты — в описании канала.

#памятка #безопасность #ЦПР
```

## 2. «Следы в телефоне» (`phone`)
```
📱 **Следы в телефоне**

Пока ничего не удалилось, сохраните:
▫️ скриншот «был(а) в сети»
▫️ голосовые сообщения
▫️ фото и видео
▫️ номера сослуживцев и друзей

Мелочь, которая кажется неважной, может оказаться нужной.

> Лучше сохранить лишнее, чем потерять нужное.

📩 Контакты — в описании канала.

#памятка #розыск #ЦПР
```

## 3. «Официальный путь» (`route`)
```
🧭 **Официальный путь**

Каждое обращение — письменно, а копию оставьте себе.

1️⃣ Командование части
2️⃣ Военкомат
3️⃣ Копии — себе

Это основа любого дальнейшего поиска. Если не знаете, как составить обращение, — напишите нам.

📩 Контакты — в описании канала.

#памятка #розыск #ЦПР
```

## 4. «Берегите себя, пока ждёте» (`care`)
```
🕯 **Берегите себя, пока ждёте**

Ожидание — тоже работа, и на неё нужны силы.

▫️ Сон. Хотя бы несколько часов.
▫️ Еда. Даже если не хочется.
▫️ Рядом — близкий человек, с которым можно молчать.

> Вы нужны своим близким. Берегите себя.

Мы рядом и ищем ответ.

📩 Контакты — в описании канала.

#забота #ЦПР
```

## 5. «Сначала — выслушаем» (`listen`)
```
💬 **Сначала — выслушаем**

Многие не пишут, потому что не знают, с чего начать. Это нормально.

Начните с чего угодно: с имени, с позывного, с одной фразы. Остальное мы уточним вместе, спокойно и без спешки.

> Расскажите то, что знаете.

📩 Контакты — в описании канала.

#памятка #розыск #ЦПР
```

Проверьте: в «Официальный путь» только общие адресаты (часть, военкомат), без номеров и сроков.
