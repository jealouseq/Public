# Рекламный ролик «Центр поисковых решений»

Моушн-ролик для Telegram-канала: 32 секунды, 1080×1080, 30 fps, красный стиль, звук.
Всё собрано кодом из открытых данных — каждый кадр детерминирован, любой текст можно поменять и пересобрать.

Про оплату в ролике ничего нет. Границ, линии фронта, техники, людей и каких-либо шокирующих кадров нет.

## Источники ассетов (все открытые)

* **NASA Black Marble 2016** — ночная Земля, огни городов (общественное достояние).
* **Natural Earth** — береговая линия 50 m, реки, озёра, города 10 m (общественное достояние). Государственных границ в ролике нет.
* **AWS Terrain Tiles (Terrarium)** — реальный рельеф района (производная SRTM и др.), для контуров и теней.
* **Шрифты** (SIL OFL, Google Fonts): Montserrat, Manrope, JetBrains Mono, Russo One.
* **Музыка и звук** — оригинальные, синтезированы в `tools/build_audio.py` (ре минор, 72 BPM). Чужих лицензий нет, подпись авторов не нужна.

## Как пересобрать

```bash
cd psr-promo
bash tools/fetch_assets.sh                      # скачать исходники и подготовить data/
python3 -I tools/build_audio.py                 # звук -> audio/score.wav
NODE_PATH=$(npm root -g) node tools/render.js seq --out out/frames --workers 4   # кадры
bash tools/encode.sh                            # сборка mp4
```

Нужны: Node 22 + `playwright` (Chromium), Python 3 + numpy + Pillow, ffmpeg.
Один кадр для проверки: `node tools/render.js still --times 12.4,27 --out /tmp/stills`.

## Где что менять

* Тексты — `src/scenes.js`, функции `drawTexts` и `drawLogoBlock` (`*слово*` — красным).
* Тайминг и музыкальные метки — `src/timeline.js` (звук и картинка берут время оттуда).
* Район работ — `R0` в `src/scenes.js` (сейчас центр 48.1° с.ш., 37.4° в.д.; рисуется нейтральная подсветка без границ).
* Размер кадра — параметры `--w` и `--h` (`1080×1920` — вертикальная версия).
