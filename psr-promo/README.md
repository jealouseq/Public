# Рекламный ролик «Центр поисковых решений» — «Рассвет»

Моушн-ролик для Telegram-канала: 32 секунды, 30 fps, со звуком. Всё собрано кодом из открытых данных,
каждый кадр детерминирован: любой текст можно поменять и пересобрать.

**Идея.** Ожидание вестей — это долгая ночь. Мы приходим со светом: рассвет над Землёй, облака расходятся над районом работ,
линии света уходят домой, к семьям по всей России. Палитра: ночная синь, тёплый янтарь огней, золото рассвета.
Фирменный красный — только акцент (маркер района и эмблема ЦПР).

## Файлы (`out/`)

| Файл | Для чего |
|---|---|
| `cpr_promo_1080x1080_compact.mp4` (~9 МБ) | **Основной для поста в канал.** Квадрат 1:1 — самый крупный и на телефоне, и на десктопе; файл меньше ~10 МБ, в ленте запускается сам |
| `cpr_promo_1080x1080.mp4` | То же, высокое качество (архив, другие площадки) |
| `cpr_promo_1080x1080_no_music.mp4` | Без музыки, эффекты сохранены: можно положить свою дорожку |
| `cpr_promo_1080x1920*.mp4` | Вертикаль 9:16 для Stories, VK Клипов, Reels, Shorts |
| `poster_*.jpg` | Кадры-обложки |

Формат: H.264 High, yuv420p, BT.709, AAC 48 кГц, громкость −14 LUFS.

## Источники (все открытые)

* **NASA Blue Marble Next Generation** — цвет поверхности Земли; **NASA Black Marble 2016** — огни городов ночью (общественное достояние).
* **NASA GIBS / VIIRS** — реальные облака за 14.09.2026 и снимок региона в разрешении 500 м (общественное достояние).
* **AWS Terrain Tiles (SRTM)** — рельеф района для теней и объёма.
* **Natural Earth** — города (общественное достояние). Государственных границ в ролике нет.
* **Шрифты** (SIL OFL): Montserrat, Manrope, JetBrains Mono, Russo One.
* **Музыка и звуки** — [Mixkit](https://mixkit.co/license/) (бесплатная лицензия, в том числе для коммерческого использования, **подпись автора не нужна**):
  трек «Rebecca on the Shore» и эффекты (удар сердца, шимер, свисты, нарастания, удары, световые искры),
  каждый эффект привязан к событию в кадре (`tools/build_audio2.py`). Файлы Mixkit в репозиторий не кладутся.

## Как пересобрать

```bash
cd psr-promo
bash tools/fetch_assets.sh          # исходники Земли и рельефа (v1) + data/
bash tools/fetch_v2.sh              # фотореальные текстуры NASA (v2)  -> assets/v2/
python3 -I tools/prep_v2.py         # -> data/day_rgb.u8, clouds.u8, region_rgb.u8
python3 -I tools/build_audio2.py && python3 -I tools/build_audio2.py --no-music     # звук
NODE_PATH=$(npm root -g) node tools/render.js seq --out out/frames2 --workers 4      # кадры 1080x1080
bash tools/encode.sh out/frames2 1080x1080                                          # mp4
# вертикаль: node tools/render.js seq --w 1080 --h 1920 --out out/frames2_v ...; BR=2900k bash tools/encode.sh out/frames2_v 1080x1920
```

Нужны: Node 22 + `playwright` (Chromium), Python 3 + numpy + Pillow, ffmpeg.
Один кадр для проверки: `node tools/render.js still --times 12.4,27 --out /tmp/stills`.
Звуковые файлы Mixkit положите в `audio/sfx_src/` и `audio/mixkit/` (см. комментарии в `tools/build_audio2.py`).

## Где что менять

* Тексты и сцены — `src/scenes2.js` (`drawTexts`, `drawLogoBlock`; `*слово*` — акцентным цветом).
* Тайминги — `src/timeline.js` (картинка и звук берут время оттуда); таблица звуков — `SFX` в `tools/build_audio2.py`.
* Район работ — `R0` в `src/scenes2.js` (рисуется нейтрально, без границ).
* Земля, свет, облака, атмосфера — `src/earth2.js`; цветокоррекция — `gradePass` в `src/overlay2.js`.
* Первая версия (красная схема) сохранена в истории git и в `src/index_v1.html`.
