# Проверка JOYRENT

Дата: 02.10.2026. Проверена локальная установка WordPress 7.1.2 + WooCommerce 11.1.2 + PHP 8.3.35, MariaDB 11.4 и Chromium 151.

## Результаты

- `npm test`: 15 тестов — все семь тарифов, несовместимый тариф PS4, смена консоли, ошибочные/прошлые даты, високосный год и переход к зимнему времени.
- PHP domain: 11 проверок тарифов и календарных дат.
- `npm run build`: TypeScript и производственная сборка проходят; создаются три устанавливаемых/просмотровых ZIP.
- Все PHP-файлы темы и плагина проходят `php -l`.
- Реальный REST: заявка сохраняется, клиентская цена игнорируется, ответ не содержит персональных данных, дубль возвращает исходный номер, изменение данных с тем же ключом отклоняется.
- Отрицательные HTTP-сценарии: неизвестная консоль/игра, неподдерживаемый срок/платформа, невозможная/прошлая дата, отсутствие согласия/адреса, некорректный телефон, заполненная ловушка и выключенный самовывоз.
- Регрессии: удалённый кэш квитанции и просроченный замок восстанавливают существующую заявку из WooCommerce; шесть параллельных одинаковых запросов создают один заказ; при остатке одного разрешённого запроса параллельная отправка создаёт один заказ, остальные получают 429.
- Проверены обычное хранилище заказов и HPOS. В заказе: `jr-request`, сумма 1400.00 для PS5/3 дня, даты/игры/геймпады, неизвестный залог отдельно со значением `pending`. Оплата не отмечена полученной.
- Семь тарифных товаров не допускают стандартную покупку/добавление в корзину, чтобы обход не пропускал даты и согласие.
- Chromium: 360/390/430/768/1003/1280/1440px, без горизонтального переполнения. Консоль/тариф/даты, категории, карусель, диалоги и фокус, согласие, настоящая отправка, неизменность квитанции после смены тарифа, мобильное меню.
- Изображения и локальные шрифты загружены; ноль JavaScript-ошибок и неудачных HTTP-ресурсов. Reduced motion и реальный Scroll Reveal проверены.
- Статический архив запускается с собственными ассетами; настоящая заявка требует WordPress.
- Независимый обзор кода принят после исправлений: прямой обход корзиной, редактируемые цены/порог доставки, снимок подтверждения, доступные названия диалогов, постоянный ключ заказа и атомарные серверные замки.

Тесты `tests/integration/*.py` создают фиктивные заявки только на отдельной локальной установке. Локальные пароли и данные окружения хранятся в ignored work/ и не включаются в репозиторий/ZIP.

Сборка готова к установке. Производственный домен/хостинг, реальные условия магазина, лицензированные игры, наличие и процесс уведомлений менеджеру нужно настроить перед публичным запуском. Проверки реального хостинга и платежей не выполнялись.
