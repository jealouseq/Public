# Проверка JOYRENT 1.1

Дата: 03.10.2026. Рабочая тестовая установка: WordPress 7.1.2, WooCommerce 11.1.2, PHP 8.3.35, MariaDB 11.4, Chromium 151. Опубликованный стенд https://flowers-luxury.shop/ проверен анонимно через браузер, без создания заявок.

- `npm test`: 16 проверок — все исходные тарифы/календарь и русские формы длительности.
- PHP domain: 15 проверок тарифов, дат и допустимых языков. Все PHP-файлы темы/плагина проходят `php -l`.
- `npm run build`: TypeScript, Vite и три ZIP версии 1.1.0 успешно собраны.
- `requests.py` и `regressions.py`: серверные цены, ручное подтверждение, ответ без персональных данных, постоянный ключ заявки, восстановление после очистки кэша, конфликт изменённых данных, шесть параллельных одинаковых запросов и атомарный лимит проходят.
- `bilingual.py`: 12 разных официальных обложек, RU-поля каталога, русская ошибка телефона, whitelist языка, повтор одной заявки после RU→UA без нового заказа, русские полные юридические страницы и ссылки возврата проходят.
- Реальная русская заявка проверена в HPOS: `jr-request`, аренда 1400 грн, `_joyrent_language=ru`, залог `pending`, оплаты нет. Обычное хранилище заказов было проверено в 1.0; в этой итерации логика поиска/блокировок сохраняется, новый контекст языка исключён из канонического отпечатка. RU-поля тарифов также исключены, чтобы старые заявки сохраняли исходные отпечатки.
- `browser.py`: 320/360/390/430/768/1003/1280/1440/1920/2560/3355 px без переполнения. Даты, безопасная смена PS5/PS4, игры/категории/карусель, диалоги/фокус, согласие, настоящая локальная заявка, неизменность квитанции, мобильное меню и sticky CTA проходят.
- `polish-browser.py`: UA/RU сохраняет имя/телефон/адрес/игры/согласие, юридический диалог переведён, сетевые ошибки локализованы, повтор использует прежний requestId. Все 12 ленивых обложек посещены и декодированы.
- Движение проверено в браузере: opacity подсветки изменяется 0.040→0.088→0.220; DualSense меняет transform при неизменной ширине layout. Переключение reduced motion останавливает оба эффекта сразу. Системный параметр отслеживается подпиской, поскольку штатный hook текущего Framer Motion не обновлялся после первого чтения.
- Собственные условия магазина проверены через read-only фильтр: город, телефон, залог и самовывоз сохраняются. Если доставка изменена на украинском без RU-перевода, исходные условия показаны с пометкой языка; настройки не заменяются выдуманными переводами. Стандартные старые изображения заменяются при чтении, собственные thumbnails сохраняют приоритет.
- Консоль JavaScript и загрузка ресурсов проверены: нет необработанных ошибок и неудачных ресурсов в обычном сценарии. Отдельный тест намеренно обрывает сеть и проверяет сообщение/retry.
- Независимый обзор кода принят после исправлений: сообщения ошибок, русские native-страницы, сохранение условий владельца и исходных отпечатков заявок. Его minor-замечание по языковой разметке исходного текста также исправлено.

Скриншоты «до/после» и анимации: [материалы проверки](audit-2026-10-03/README.md). Итог визуального контроля: [passed](../design-qa.md).

Тесты создают фиктивные заявки только на локальной установке. Пароли и данные окружения находятся в ignored `work/`, в Git/ZIP не включены. Стенд на хостинге не изменён этой работой: готовые 1.1 ZIP нужно загрузить через замену темы/плагина и очистить кэш. Оплата, складской календарь и уведомления менеджеру не добавлялись.
