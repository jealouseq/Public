| C13 — unknown delivery amount | «За адресою / По адресу» вместо значения | «Підтвердимо» | «Подтвердим» |

Динамические подписи должны склоняться по числу, а не показывать варианты в скобках. Формы с «до» требуют родительного: «До 2 локальних гравців / До 2 локальных игроков» в описании возможностей сами по себе корректны. Для единственного игрока стоит явно написать «1 локальний гравець / 1 локальный игрок», чтобы не смешивать локальный и сетевой режим.

Ошибка каталога «Не вдалося завантажити каталог. Твій вибір збережено / Не удалось загрузить каталог. Твой выбор сохранён» соответствует поведению текущей формы и полезна; оставить. Базовые labels имени, телефона, даты/возврата, способы получения, Continue/Send и receipt reference менять не требуется. «Оплата не нужна» достаточно один раз рядом с Submit и один раз на успехе; в остальных разделах не размножать.

## Авторизованный implementation / проверки

Root разрешил точечные исправления в Booking/Tariffs/Games/GamePresentation/GamePicker/API fallback. Выполнены C03/C04/C06–C16/C21: склонение геймпадов и локальных игроков, грамматика лимита игр, короткие состояния формы и доступности, отдельный залог в пояснении итога, общая оговорка зон для отмеченных звёздочкой тарифов. Общая оговорка находится внутри существующего `.tariff-conditions` рядом с ссылкой о получении консоли; отдельного дополнительного ряда под тарифами нет. В picker сокращено пустое состояние категории; C18 для основного carousel оставлено как необязательная редакционная рекомендация.

Авторские описания игр сохранены. Повторный internet-note скрывается только при наличии точного существующего UA/RU предложения о требовании подключения в показанном описании; для custom description без него note сохраняется. API fallback использует тот же согласованный текст доставки, что и backend managed default. Суммы, контакты, условия доставки, draft и отправка заявки не изменены. Production Hero/Footer/Story/CSS/App/PHP этим исполнителем в рамках 1.7 не менялись.

Перед helper-реализацией `npm test -- src/lib/copy.test.ts --reporter=dot` дал ожидаемый отказ из-за отсутствующего модуля. После реализации эти четыре проверки прошли: UA/RU геймпады, локальные игроки, лимит 1/2/11/21/100, подавление только известного internet-предложения. `npx tsc --noEmit` завершился успешно. Проверки полного release и браузерные снимки новой компоновки выполняет root/QA; этот отчёт не выдаёт source audit за проверку всех живых авторских WP-страниц.

## Примечание к final fixture

Internet-note зависит от показанного текста, а не ID BO7: если сохранённое авторское описание не содержит точного известного предложения, отдельная заметка корректно остаётся. Краткий fallback доставки и текущий live GET не заменяют сохранённый авторский локальный текст; его повтор условий на QA-снимке отражает fixture, а не принудительную перезапись владельца.
