# Проверка опубликованного JOYRENT — 3 октября 2026

Источник: https://flowers-luxury.shop/. Проверка анонимного посетителя в браузере: 3355×1274 и 390×844. Скриншоты сняты до изменений; реальные заявки на хостинге не отправлялись.

| Приоритет | Наблюдение | Изменение |
|---|---|---|
| P1 | Hero использует изображение `cover` на всю ширину экрана: на ultrawide срезает консоль и DualSense, на телефоне контроллер выходит за край. | Ограниченная продуктовая сцена, целая консоль и контроллер; отдельная плавная анимация тёплого света. |
| P1 | MK11, Tekken 8, UFC 5 и MK1 используют один выдуманный постер. Другие картинки тоже изображают жанр, а не конкретную игру. | Официальные материалы PlayStation для каждой игры; убрать наложенные названия поверх официальных логотипов. |
| P2 | Движение крупного обрезанного DualSense связано с изменением ширины при прокрутке. | Полный контроллер с прозрачным фоном; плавный transform без изменения геометрии блока; режим reduced motion. |
| P2 | Комплект, пять шагов, доставка и калькулятор повторяют информацию, сбивая путь к заявке. | Комплект объединён с контроллером; три этапа вместо пяти; убрать номера полей и повтор цены в списке расчёта. |
| P2 | FAQ и огромный финальный призыв имеют похожую левую композицию и одинаковый фон. | Конкретный заголовок FAQ; компактный контрастный призыв в отдельной панели. |
| P2 | Сайт только украинский. | UA/RU: навигация, форма, игры, юридические тексты, ошибки и результат заявки; сохранение выбора и формы при смене языка. |

Горизонтального переполнения на проверенных ширинах нет. Ошибок JavaScript в сессиях не обнаружено. Город, контакты, застава, доступность игр и стоимость доставки требуют настроек владельца; не заменяются выдуманными условиями.

Свежие доказательства: [desktop](live-desktop.png), [mobile](live-mobile.png), [games](live-desktop-games.png), [DualSense](live-desktop-controller.png), [FAQ](live-desktop-faq.png).

Принятая структура: первый экран → тарифы → игры → комплект → процесс и доставка → заявка → FAQ → компактный призыв и контакты.

Референс движения текста: [Reveal Text, EduCalvo / 21st.dev](https://21st.dev/@educalvolpz/components/reveal-text). Используем только спокойное появление строк; текущий Framer Motion уже обеспечивает нужное поведение. Остальные эффекты не нужны для аренды.
