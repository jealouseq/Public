# Установка JOYRENT

Готовые архивы в `releases/`: `joyrent-1.0.0.zip` — тема, `joyrent-rentals-1.0.0.zip` — плагин. Третий архив — только статический визуальный просмотр.

## WordPress

1. Установите WordPress и WooCommerce на PHP 8.2+. Сборка проверена на WordPress 7.1.2, WooCommerce 11.1.2 и PHP 8.3; плагин требует WordPress 6.6+, WooCommerce 8.2+.
2. В **Налаштування → Загальні** выберите українську мову и часовой пояс **Київ**. В WooCommerce установите валюту **UAH / гривня**.
3. **Плагіни → Додати → Завантажити плагін**: загрузите `joyrent-rentals-1.0.0.zip` и активируйте после WooCommerce.
4. **Вигляд → Теми → Додати → Завантажити тему**: загрузите `joyrent-1.0.0.zip` и активируйте JOYRENT. На главной автоматически появляется страница аренды.
5. **WooCommerce → JOYRENT**: заполните город/зону/часы доставки, телефон или Telegram, размер залога для обеих консолей, доставку коротких тарифов, количество геймпадов и стоимость дополнительного. Пустая сумма означает «узгодимо», значение `0` — бесплатно. Дополнительный геймпад тарифицируется за весь срок.
6. При необходимости включите самовывоз. Укажите в тексте доставки место получения, часы и условия возврата. Бесплатная доставка от 7 дней уже настроена; порог можно изменить.
7. В **Товари** проверьте семь товаров со SKU `joyrent-ps5-1`, `joyrent-ps5-3`, `joyrent-ps5-7`, `joyrent-ps5-30`, `joyrent-ps4-3`, `joyrent-ps4-7`, `joyrent-ps4-30`. Цена берётся из этих товаров. Не меняйте SKU/служебные поля. Публикация и положительная цена каждого тарифа нужны для приёма заявок. Каталог можно восстановить кнопкой **Додати початковий каталог**; существующие товары и цены она не перезаписывает.
8. В **Ігри JOYRENT** отредактируйте доборку, платформы, описание и обложки. Подтвердите фактически доступные лицензированные игры. Неактуальные позиции переводите в черновики. Иллюстрации исходного сайта — авторские изображения для доборки, а не официальная упаковка игр.
9. Отредактируйте страницы **Умови оренди** и **Конфіденційність** с реквизитами и реальным процессом магазина; выберите страницу конфиденциальности в WordPress. Встроенные краткие тексты описывают только отправку заявки. Полные страницы доступны по ссылкам из формы.
10. В **Постійні посилання** сохраните структуру ссылок. REST должен быть доступен по `/wp-json/joyrent/v1/catalog`; с обычными ссылками WordPress использует `?rest_route=` автоматически. Исключите `/joyrent/v1/requests` из кэширования POST; администраторские страницы не должны попадать в публичный кэш.

Тема не меняет существующую валюту магазина и не удаляет товары/заказы при деактивации. В новом пустом магазине импорт задаёт UAH. Готовые ZIP включают JS/CSS, локальные шрифты и WebP; сборка на сервере не нужна.

## Проверка после установки

- Откройте главную на телефоне и компьютере. Переключите PS5/PS4, выберите тариф и игру, задайте дату.
- Отправьте свою тестовую заявку. Убедитесь, что в WooCommerce появилась **«Заявка на оренду»**, сумма, даты, телефон, адрес и выбранные игры. Повторный запрос с тем же идентификатором не создаёт второй заказ.
- Проверьте, что доставка и залог соответствуют настройкам; неизвестные суммы показаны как согласование, залог хранится отдельно от стоимости аренды.
- Согласуйте условия с клиентом вручную. Базовая версия не ведёт календарь доступности и не принимает оплату. Для автоматического бронирования нужна отдельная настройка количества консолей/пересечений дат и платёжного процесса.

Заявки находятся в обычном списке заказов WooCommerce. Плагин не отправляет уведомления менеджеру самостоятельно. Настройте рабочий процесс просмотра заявок; почтовые/Telegram-уведомления подключаются отдельно к выбранному каналу.

## Исходники и локальные проверки

```bash
npm ci
npm test
npm run build
npm run preview
```

Форматирование файлов сборки и ZIP автоматическое. Для настоящей отправки нужен локальный или установленный WordPress; статический preview не имитирует успех. Интеграционные Python-тесты запускайте только на отдельной тестовой установке: они создают тестовые заявки.

При обновлении загрузите новые архивы обычным механизмом замены темы/плагина. Настройки, игры, тарифы и заявки останутся в базе WordPress. Сохраняйте резервную копию базы и uploads.
