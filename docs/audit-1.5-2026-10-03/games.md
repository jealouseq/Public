# JOYRENT 1.5: фактическая проверка игрового каталога

Проверка 3 октября 2026 года. Сверены свежий публичный REST-каталог стенда, исходный каталог сборки, официальный HTML издателей и PlayStation, пять текущих WebP-обложек. Это проверка сведений об играх; она не подтверждает наличие лицензий у магазина и не является рейтингом популярности по Украине. Продуктовые файлы не менялись.

## Что исправить в данных

1. **P2, платформозависимые локальные игроки.** У BO7 хранить PS5=2, PS4=1; у GT7 PS5=4, PS4=2. Число на карточке и категории «На двох / Вдвоём», «Для компанії / Для компании» должны зависеть от выбранной консоли и подтверждённого установленного издания. У PS4 BO7 нельзя обещать split-screen. На PS5 BO7 нельзя обещать автономную игру без интернета. Для сетевых режимов PlayStation указывает требование PS Plus; конкретные режимы и учётные записи подтверждает магазин.
2. **P3, точность краткой карточки.** В деталях BO7 достаточно одной ясной строки «Потрібен інтернет / Нужен интернет», вместо полностью неопределённого согласования требований. При этом онлайн-доступ магазина нельзя считать подтверждённым только по возможностям игры. У GT7 полезно показывать 4 или 2 в зависимости от консоли, не превращая карточку в таблицу всех режимов.
3. **Последняя выпущенная версия, а не ближайший анонс.** На свежей странице BO7 есть MW4 в предзаказе. Сам факт анонса не означает, что надо заменить выпущенную игру в аренде. Версии FC 27/UFC 6/BO7 допустимы; их текущий выпуск проверен по официальным страницам. Каталог нужно обновлять после фактического выпуска и проверки лицензии/издания магазина.

Визуально проверены текущие FC27, UFC6, BO7, STALKER2 и Requiem: логотипы и композиции относятся к соответствующим играм; это не сгенерированные похожие постеры. Все пять изображений в сборке 720×720. Проверены источники из `docs/game-artwork-sources.json`: URL FC27 standard key art присутствует в свежем официальном HTML EA; точные URL четырёх остальных присутствуют в свежем HTML соответствующих официальных SKU PlayStation Store. Квадратная композиция соответствует текущему квадратному формату карточки. Эта проверка происхождения не оценивает реальную лицензию магазина.

## Приоритет для украинской аудитории

Существующий порядок FC → GTA → Mortal Kombat → S.T.A.L.K.E.R. → UFC → Tekken → совместные приключения является обоснованной редакционной подборкой для аренды: узнаваемые серии, совместная игра, украинский контекст. Числового подтверждения, что это точный рейтинг спроса по Украине, нет. Не подписывать его «топ продаж Украины» или «чаще всего арендуют», пока магазин не располагает такими данными. После запуска порядок лучше корректировать по собственным выбранным играм/подтверждённым заявкам. Удалять оригинальные серии только ради новизны также не нужно: разделить новинки и совместную игру можно фильтрами, сохранив один список без дублей.
