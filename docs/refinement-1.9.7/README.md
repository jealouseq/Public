# JOYRENT 1.9.7 — просмотр выбранных игр

6 октября 2026. Продолжение точечных улучшений существующего раздела игр. По просьбе владельца проверка выполняется **только локально**, без живого сайта со старой версией. FAQ остаётся отдельной страницей.

## Изменения

- В закреплённой нижней панели подборки теперь можно открыть выбранные игры. В этом просмотре кнопка «Убрать» явно удаляет игру; возвращение в каталог восстанавливает прежний поиск и категорию. Дополнительная панель над каталогом не занимает место на телефоне.
- При удалении карточки фокус возвращается к доступной кнопке просмотра; после удаления последней игры и возврата в каталог — к области результатов. Tab и Shift+Tab замыкаются на границах окон подборки и описания игры; закрытие по Escape и возврат к кнопке открытия сохраняются. Сочетания клавиш с Ctrl/Alt/Meta не перехватываются.
- Блок «Не нашли игру?» объясняет, что название передаётся как пожелание для проверки возможности добавить игру к аренде. Пустой поиск имеет один путь для такого пожелания; запрос подставляется в поле. Сохранённое пожелание доступно и в просмотре выбранного.
- Заголовок каталога показывает активную консоль PS5/PS4. Стрелки учитывают край ленты, число карточек и изменение ширины окна: недоступное направление отключено.

Размеры обложек и схема открытой карточки сохранены. Пожелание остаётся в памяти формы, не попадает в browser storage и не означает гарантированную доступность игры. Расчёт цен, даты, отправка брони и PHP-плагин не изменены.

## Проверки

- [Просмотр выбора, поиск, возврат фокуса, UA/RU, лимит и узкое окно](selection-check.json): 20 сценариев на локальном WordPress с WooCommerce; основные ширины 320, 390, 768 и 1440 px, компактное окно высотой 320 px.
- [Отсутствующая игра](search-check.json): один путь, подстановка запроса, фокус и сохранение пожелания в обеих языковых версиях.
- [Карточки игр](game-details/game-detail-layout.json): 186 открытий, шесть вложенных окон, два длинных авторских описания и два случая достижения лимита.
- 123 модульных теста прошли; TypeScript и установочные архивы собраны.
- [Целостность ZIP и сохранение прошлых выпусков](package-check.json); [результат и ограничения](verification.json).

Новые проверки сначала выявили отсутствие просмотра выбранного и неверное состояние стрелки на старте. Клавиатурный сценарий выявил выход Tab за границу нативного окна; после исправления повторный проход успешен. Внешние сайты, реальные брони и уведомления в этом выпуске не проверялись и не отправлялись. Chromium с эмуляцией касания не заменяет проверку физического iPhone Safari. Прежнее предупреждение Vite о размере основного JS-файла остаётся.

## Установка

Замените текущую тему архивом `joyrent-1.9.7.zip` через «Внешний вид → Темы → Добавить → Загрузить тему», затем очистите кэш сайта/CDN. При установленном Rentals 1.8.4 плагин повторно устанавливать не нужно. Выпуск 1.9.7 включает изменения темы 1.9.6; устанавливать их по очереди не требуется.
